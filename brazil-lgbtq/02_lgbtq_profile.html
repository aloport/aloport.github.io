How Do LGBTQ+ Candidates Differ from the Average?

1 Overview

The previous chapter established who runs for municipal office in Brazil. This chapter asks the central comparative question: How do LGBTQ+ candidates differ from their non-LGBTQ+ counterparts?

We compare the two groups across demographics (age, gender, race, education), political positioning (ideology, party, position), and electoral outcomes. Every comparison shown here treats the non-LGBTQ+ population as the baseline and highlights where LGBTQ+ candidates diverge — and by how much.

The dataset contains 933,466 candidates, of whom 12,532 (1.3%) are identified as LGBTQ+.

2 Identification Overview

2.1 How Were LGBTQ+ Candidates Identified?

LGBTQ+ candidates in this dataset were identified through two complementary sources:

  • TSE (Tribunal Superior Eleitoral): For the first time in 2024, the TSE allowed candidates to voluntarily declare their sexual orientation and gender identity on official registration forms.
  • VOTE LGBT: A civil society project that independently identified LGBTQ+ candidates through public campaigning, social media presence, and community referrals.

Some candidates appear in both sources, which strengthens confidence in their identification. Disclosure source indicates whether a candidate was identified via TSE self-declaration only, VOTE LGBT matching only, or both. The table below shows the distribution across these categories.

5.2 Election Rate by Position

The aggregate comparison may mask important differences across position types. Below we disaggregate by city councilor and mayor races.

Show code 
df %>%
  filter(!is.na(elected), !is.na(lgbtq_label)) %>%
  group_by(position_simple, lgbtq_label) %>%
  summarise(
    N = n(),
    Elected = sum(elected),
    Rate = mean(elected),
    .groups = "drop"
  ) %>%
  rowwise() %>%
  mutate(
    ci = list(binom.test(Elected, N)$conf.int),
    CI_low = ci[1],
    CI_high = ci[2]
  ) %>%
  ungroup() %>%
  select(-ci) %>%
  mutate(
    `Election Rate` = format_pct(Rate),
    `95% CI` = paste0("[", format_pct(CI_low), ", ", format_pct(CI_high), "]"),
    N = format_n(N),
    Elected = format_n(Elected)
  ) %>%
  select(Position = position_simple, Group = lgbtq_label, N, Elected, `Election Rate`, `95% CI`) %>%
  kable(align = c("l", "l", "r", "r", "r", "r"))
Why Confidence Intervals Matter

With a much smaller LGBTQ+ sample, confidence intervals are substantially wider. A point estimate that looks different may not be statistically distinguishable from the non-LGBTQ+ rate once uncertainty is accounted for. Always read the CIs alongside the point estimates.

7 Summary

This chapter documents how LGBTQ+ candidates compare with the general candidate pool across several dimensions:

  1. Demographics: The data reveal the extent to which LGBTQ+ candidates differ from non-LGBTQ+ counterparts in age, racial composition, and educational attainment — with implications for understanding who gains access to candidacy.
  2. Ideology: The ideological distribution of LGBTQ+ candidates is compared to the non-LGBTQ+ baseline, showing the degree to which LGBTQ+ candidates concentrate in particular parts of the left-right spectrum.
  3. Party concentration: LGBTQ+ candidates are not uniformly distributed across parties. Some parties serve as key vehicles for LGBTQ+ candidacies while others have virtually none.
  4. Electoral outcomes: The comparison of election rates between LGBTQ+ and non-LGBTQ+ candidates provides a critical descriptive finding that sets the stage for understanding representation gaps.

However, treating “LGBTQ+” as a monolithic category obscures crucial within-group variation. The next chapter disaggregates this umbrella into its constituent identities — Gay, Lesbian, Bisexual+, and Trans — to reveal the heterogeneity that the binary comparison conceals.

# Publication-Ready Table 1 {#sec-table1}

The table below consolidates all major comparisons into a single summary statistics table suitable for inclusion in a research paper. For each variable, we report the statistic for non-LGBTQ+ and LGBTQ+ candidates, along with a formal test of difference. All variable definitions follow Chapter 1.

- **Continuous variables** (age, ideology score): Welch's *t*-test
- **Categorical variables** (gender, race, education, ideology category, position): Pearson's chi-squared test

```{r tbl-table1}
#| output: asis
#| echo: false

# Helper: format mean(sd)
fmt_mean_sd <- function(x) {
  paste0(round(mean(x, na.rm = TRUE), 1), " (", round(sd(x, na.rm = TRUE), 1), ")")
}

# Helper: format proportion
fmt_prop <- function(x, val) {
  format_pct(mean(x == val, na.rm = TRUE))
}

cat("\n::: {.panel-tabset}\n\n")
for (pos_name in names(position_filters)) {
  cat(paste0("### ", pos_name, "\n\n"))
  d <- filter_position(df, position_filters[[pos_name]])

  # Prepare subsets
  df_compare <- d %>% filter(!is.na(lgbtq_label))
  df_lgbtq <- df_compare %>% filter(lgbtq_label == "LGBTQ+")
  df_non   <- df_compare %>% filter(lgbtq_label == "Non-LGBTQ+")

  # --- Continuous variables ---
  # Age
  t_age_tab <- t.test(age ~ lgbtq_label, data = df_compare)
  age_row <- tibble(
    Variable = "Age, mean (SD)",
    `Non-LGBTQ+` = fmt_mean_sd(df_non$age),
    `LGBTQ+` = fmt_mean_sd(df_lgbtq$age),
    Test = paste0("t = ", round(t_age_tab$statistic, 2),
                  ", p ", ifelse(t_age_tab$p.value < 0.001, "< 0.001", paste0("= ", round(t_age_tab$p.value, 3))))
  )

  # Ideology score
  t_ideo <- t.test(ideology_score ~ lgbtq_label, data = df_compare)
  ideo_row <- tibble(
    Variable = "Ideology score, mean (SD)",
    `Non-LGBTQ+` = fmt_mean_sd(df_non$ideology_score),
    `LGBTQ+` = fmt_mean_sd(df_lgbtq$ideology_score),
    Test = paste0("t = ", round(t_ideo$statistic, 2),
                  ", p ", ifelse(t_ideo$p.value < 0.001, "< 0.001", paste0("= ", round(t_ideo$p.value, 3))))
  )

  # --- Categorical variables (use safe_chisq_str for small-N robustness) ---
  # Gender: % Female
  gender_row <- tibble(
    Variable = "Female, %",
    `Non-LGBTQ+` = format_pct(mean(df_non$female, na.rm = TRUE)),
    `LGBTQ+` = format_pct(mean(df_lgbtq$female, na.rm = TRUE)),
    Test = safe_chisq_str(df_compare %>% filter(!is.na(female)) %>%
                           with(table(lgbtq_label, female)))
  )

  # Nonwhite
  nonwhite_row <- tibble(
    Variable = "Nonwhite, %",
    `Non-LGBTQ+` = format_pct(mean(df_non$nonwhite, na.rm = TRUE)),
    `LGBTQ+` = format_pct(mean(df_lgbtq$nonwhite, na.rm = TRUE)),
    Test = safe_chisq_str(df_compare %>% filter(!is.na(nonwhite)) %>%
                           with(table(lgbtq_label, nonwhite)))
  )

  # Race (full breakdown)
  race_test_str <- safe_chisq_str(df_compare %>% filter(!is.na(race_simple)) %>%
                                   with(table(lgbtq_label, race_simple)))
  race_rows <- tibble(
    Variable = c("Race", "  White, %", "  Black, %", "  Brown, %", "  Other, %"),
    `Non-LGBTQ+` = c(
      "",
      fmt_prop(df_non$race_simple, "White"),
      fmt_prop(df_non$race_simple, "Black"),
      fmt_prop(df_non$race_simple, "Brown"),
      fmt_prop(df_non$race_simple, "Other")
    ),
    `LGBTQ+` = c(
      "",
      fmt_prop(df_lgbtq$race_simple, "White"),
      fmt_prop(df_lgbtq$race_simple, "Black"),
      fmt_prop(df_lgbtq$race_simple, "Brown"),
      fmt_prop(df_lgbtq$race_simple, "Other")
    ),
    Test = c(race_test_str, "", "", "", "")
  )

  # Education
  edu_test_str <- safe_chisq_str(df_compare %>% filter(!is.na(education_simple)) %>%
                                  with(table(lgbtq_label, education_simple)))
  edu_rows <- tibble(
    Variable = c("Education", "  Less than HS, %", "  High School, %", "  College+, %"),
    `Non-LGBTQ+` = c(
      "",
      fmt_prop(df_non$education_simple, "Less than HS"),
      fmt_prop(df_non$education_simple, "High School"),
      fmt_prop(df_non$education_simple, "College+")
    ),
    `LGBTQ+` = c(
      "",
      fmt_prop(df_lgbtq$education_simple, "Less than HS"),
      fmt_prop(df_lgbtq$education_simple, "High School"),
      fmt_prop(df_lgbtq$education_simple, "College+")
    ),
    Test = c(edu_test_str, "", "", "")
  )

  # Ideology category
  ideol_test_str <- safe_chisq_str(df_compare %>% filter(!is.na(ideology_category)) %>%
                                    with(table(lgbtq_label, ideology_category)))
  ideol_rows <- tibble(
    Variable = c("Ideology category", "  Left, %", "  Center, %", "  Right, %"),
    `Non-LGBTQ+` = c(
      "",

      fmt_prop(df_non$ideology_category, "Center"),
      fmt_prop(df_non$ideology_category, "Right")
    ),
    `LGBTQ+` = c(

      fmt_prop(df_lgbtq$ideology_category, "Left"),
      fmt_prop(df_lgbtq$ideology_category, "Center"),
      fmt_prop(df_lgbtq$ideology_category, "Right")

  )

  # Elected
  elected_row <- tibble(
    Variable = "Elected, %",
    `Non-LGBTQ+` = format_pct(mean(df_non$elected, na.rm = TRUE)),
    `LGBTQ+` = format_pct(mean(df_lgbtq$elected, na.rm = TRUE)),

                           with(table(lgbtq_label, elected)))
  )

  # N row
  n_row <- tibble(
    Variable = "N",
    `Non-LGBTQ+` = format_n(nrow(df_non)),

  # Bind all rows
```

# Summary

This chapter documents how LGBTQ+ candidates compare with the general candidate pool across several dimensions:

1. **Demographics**: The data reveal the extent to which LGBTQ+ candidates differ from non-LGBTQ+ counterparts in age, racial composition, and educational attainment --- with implications for understanding who gains access to candidacy.
2. **Ideology**: The ideological distribution of LGBTQ+ candidates is compared to the non-LGBTQ+ baseline, showing the degree to which LGBTQ+ candidates concentrate in particular parts of the left-right spectrum.
3. **Party concentration**: LGBTQ+ candidates are not uniformly distributed across parties. Some parties serve as key vehicles for LGBTQ+ candidacies while others have virtually none.
4. **Electoral outcomes**: The comparison of election rates between LGBTQ+ and non-LGBTQ+ candidates provides a critical descriptive finding that sets the stage for understanding representation gaps.

However, treating "LGBTQ+" as a monolithic category obscures crucial within-group variation. The next chapter disaggregates this umbrella into its constituent identities --- Gay, Lesbian, Bisexual+, and Trans --- to reveal the heterogeneity that the binary comparison conceals.
